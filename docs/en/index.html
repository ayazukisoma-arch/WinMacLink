Control your Mac from Windows with WinMacLink

WinMacLink is a free tool that lets you operate a Mac from a Windows x64 PC connected directly by Ethernet.

Download for Windows x64

Share one keyboard and mouse across two displays

Keep a monitor connected to each computer. Move the pointer beyond the edge of your Windows screen to control the Mac. WinMacLink uses Deskflow for input sharing.

View and control your Mac desktop in a Windows window

Open the Mac desktop from Windows and operate it inside the viewer. WinMacLink uses VNC over an SSH tunnel for remote desktop control.

First-time setup

Extract the whole ZIP and run WinMacLink.exe on Windows. The app guides you through macOS Remote Login and the permissions for your chosen mode. If you use input sharing, WinMacLink downloads Deskflow from its official distribution.
