WindowsからMacを操作する WinMacLink

WindowsとMacをLANケーブルで直結し、WindowsのマウスとキーボードでMacを操作できる無料ツールです。Windows x64が操作元で、Macが接続先です。

Windows x64版をダウンロード

2台のモニターでマウスとキーボードを共有

WindowsとMacにそれぞれモニターを接続します。Windowsの画面端にカーソルを動かすと、そのままMacを操作できます。入力共有にはDeskflowを使います。

Windowsのウィンドウ内にMacの画面を表示

MacのデスクトップをWindowsで表示し、そのウィンドウで操作できます。画面表示はVNCを使い、通信をSSHトンネルに通します。

初回セットアップ

ZIPをすべて展開し、Windowsで WinMacLink.exe を開きます。Mac側のリモートログインや、使う機能に応じた操作許可の手順が表示されます。Deskflowが必要な場合は、初回セットアップで公式配布元から取得します。
